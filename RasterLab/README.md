# Отчёт по лабораторной работе № 4

## «Базовые растровые алгоритмы»

### 1. Цель работы

Изучить принципы растеризации графических примитивов и реализовать алгоритмы построения отрезков и окружностей на дискретной сетке. Сравнить алгоритмы по принципу работы и времени выполнения.

### 2. Средства разработки

Приложение реализовано с использованием HTML, CSS и JavaScript. Для отображения графики используется элемент `canvas`.

Построение выполняется на виртуальной растровой сетке. Алгоритм определяет, какие пиксели необходимо закрасить, после чего приложение отображает полученный результат. Такой подход позволяет отдельно выполнять растеризацию и вывод изображения на экран.

### 3. Реализованные алгоритмы

#### 3.1. Пошаговый алгоритм построения отрезка

Пошаговый алгоритм строит отрезок, последовательно переходя от начальной точки к конечной. На каждом шаге вычисляются координаты следующей точки, после чего они округляются до ближайших целых значений — координат пикселя.

Пусть заданы точки:

\\[ A(x_1,y_1), \quad B(x_2,y_2) \\]

Вычисляются приращения координат:

\\[ \Delta x=x_2-x_1,\qquad \Delta y=y_2-y_1 \\]

Количество шагов выбирается по наибольшему из приращений:

\\[ N=\max(|\Delta x|,|\Delta y|) \\]

Шаги изменения координат равны:

\\[ x\_{\text{ш}}=\frac{\Delta x}{N},\qquad y\_{\text{ш}}=\frac{\Delta y}{N} \\]

Начиная с точки \\(A\\), алгоритм выполняет \\(N\\) шагов. На каждом шаге координаты увеличиваются на соответствующие приращения, округляются и отображаются на сетке.

Особенности алгоритма:

- простая реализация;
- поддерживает отрезки с разными наклонами и направлениями;
- использует вещественные вычисления и округление;
- результат может зависеть от накопления погрешности при последовательном прибавлении приращений.

#### 3.2. Алгоритм цифрового дифференциального анализатора (ЦДА, DDA)

Алгоритм ЦДА также строит отрезок последовательным вычислением координат пикселей. Его основная идея — изменять координаты с постоянными приращениями, выбирая число шагов так, чтобы на каждом шаге изменялась координата вдоль главного направления отрезка.

Для заданных точек вычисляются:

\\[ \Delta x=x_2-x_1,\qquad \Delta y=y_2-y_1 \\]

Затем определяется число шагов:

\\[ N=\max(|\Delta x|,|\Delta y|) \\]

Приращения координат на каждом шаге:

\\[ x\_{\text{ш}}=\frac{\Delta x}{N},\qquad y\_{\text{ш}}=\frac{\Delta y}{N} \\]

Алгоритм начинает работу с координат \\((x_1,y_1)\\). После каждого шага к текущим координатам прибавляются \\(x\_{\text{ш}}\\) и \\(y\_{\text{ш}}\\), а полученные значения округляются до целых координат пикселя.

В отличие от пошагового построения, ЦДА обычно описывается как метод, в котором приращения вычисляются один раз и используются на протяжении всего построения. В данной реализации он также опирается на последовательное вычисление координат и округление.

Особенности алгоритма:

- подходит для отрезков любого наклона;
- использует простые вычисления;
- требует операций с вещественными числами;
- при большом количестве шагов может накапливать погрешность округления.

#### 3.3. Алгоритм Брезенхема для построения отрезка

Алгоритм Брезенхема позволяет строить отрезок с использованием преимущественно целочисленных вычислений. На каждом шаге он выбирает один из двух соседних пикселей, наиболее близкий к идеальному положению линии.

Сначала вычисляются:

\\[ \Delta x=|x_2-x_1|,\qquad \Delta y=|y_2-y_1| \\]

Также определяются направления изменения координат:

\\[ s_x= \begin{cases} 1, & x_1\<x_2\\\ -1, & x_1\ge x_2 \end{cases} \qquad s_y= \begin{cases} 1, & y_1\<y_2\\\ -1, & y_1\ge y_2 \end{cases} \\]

Для учёта разных наклонов используется параметр ошибки. В реализации алгоритм обрабатывает случаи, когда линия идёт преимущественно вдоль оси \\(X\\), и когда она идёт преимущественно вдоль оси \\(Y\\). Благодаря этому алгоритм корректно строит отрезки во всех восьми октантах.

Для каждого следующего пикселя алгоритм обновляет параметр ошибки. Если ошибка показывает, что идеальная линия отклонилась достаточно далеко от текущего пикселя, изменяется и вторая координата. В противном случае изменяется только координата вдоль главного направления.

Особенности алгоритма:

- использует целочисленные вычисления;
- не требует вычисления координат с плавающей точкой на каждом шаге;
- строит отрезки с разными наклонами и направлениями;
- обычно эффективен для растеризации линий.

#### 3.4. Алгоритм Брезенхема для построения окружности

Алгоритм Брезенхема для окружности строит её по одному октанту, используя симметрию окружности. Если центр окружности имеет координаты \\((x_c,y_c)\\), а радиус равен \\(r\\), то сначала рассматривается точка в верхней части окружности, например:

\\[ x=0,\qquad y=r \\]

Далее алгоритм последовательно выбирает следующие пиксели, приближаясь к границе окружности. Для этого используется целочисленный параметр решения, который определяет, следует ли уменьшить \\(y\\) на очередном шаге.

Окружность симметрична относительно горизонтальной и вертикальной осей, а также диагоналей. Поэтому для каждой найденной точки \\((x,y)\\) относительно центра строятся восемь симметричных точек:

\\[ (x_c+x,\ y_c+y),\quad (x_c-x,\ y_c+y) \\]

\\[ (x_c+x,\ y_c-y),\quad (x_c-x,\ y_c-y) \\]

\\[ (x_c+y,\ y_c+x),\quad (x_c-y,\ y_c+x) \\]

\\[ (x_c+y,\ y_c-x),\quad (x_c-y,\ y_c-x) \\]

Построение продолжается до тех пор, пока координаты не достигнут границы первого октанта. Таким образом, для получения всей окружности достаточно вычислить только её часть, а остальные точки получить отражением.

Особенности алгоритма:

- использует целочисленные вычисления;
- применяет восьмикратную симметрию окружности;
- не требует вычисления квадратного корня для каждой точки;
- позволяет строить окружности с разными радиусами.

#### 3.5. Алгоритм Ву для сглаживания отрезка

Алгоритм Ву используется для построения сглаженных линий. В отличие от обычных растровых алгоритмов, он может закрашивать соседние пиксели с разной интенсивностью.

Идея алгоритма заключается в том, что вклад пикселя зависит от расстояния идеальной линии до его центра. Чем ближе линия к центру пикселя, тем выше его интенсивность. Соседние пиксели получают меньшую интенсивность, благодаря чему граница линии выглядит более плавной.

Алгоритм учитывает наклон отрезка. Для удобства построения координаты могут меняться местами, если отрезок круче диагонали. После этого линия обрабатывается по главному направлению, а интенсивности пикселей определяются по дробной части вычисленной координаты.

Особенности алгоритма:

- уменьшает ступенчатость линий;
- использует частичную интенсивность пикселей;
- требует большего количества вычислений, чем обычные алгоритмы растеризации;
- применяется, когда важнее визуальная гладкость линии.

### 4. Интерфейс приложения

Приложение содержит область построения, панель управления и раздел тестирования производительности.

Пользователь может выбрать алгоритм, задать координаты отрезка или параметры окружности и выполнить построение. Масштаб сетки изменяется вместе с масштабом отображения, что позволяет рассматривать построенные примитивы при разных уровнях увеличения.

Для сравнения алгоритмов предусмотрен отдельный раздел с графиками и таблицей результатов. Результаты измерений можно сохранить в CSV-файл.

### 5. Тестирование производительности

Для оценки производительности в приложении предусмотрен бенчмарк. Он измеряет время выполнения алгоритмов на наборах отрезков и окружностей и отображает результаты отдельно для разных алгоритмов.

Измерения позволяют сравнить количество времени, необходимое каждой реализации для обработки входных данных. При интерпретации результатов следует учитывать, что время зависит от характеристик компьютера, браузера и объёма тестовых данных.

### 6. Результат работы

В ходе лабораторной работы разработано веб-приложение для построения растровых отрезков и окружностей. Реализованы пошаговый алгоритм, алгоритм ЦДА, алгоритм Брезенхема для отрезка и окружности, а также алгоритм Ву для сглаживания линий.

В приложении предусмотрены масштабируемая сетка, управление параметрами построения и инструменты сравнения времени выполнения алгоритмов.

### 7. Вывод

В ходе лабораторной работы были изучены принципы растеризации графических примитивов. Реализованные алгоритмы показывают разные подходы к выбору пикселей: от последовательного вычисления координат до целочисленного выбора ближайшего пикселя и сглаживания с помощью интенсивности.

Алгоритмы Брезенхема позволяют строить отрезки и окружности с использованием целочисленных вычислений. Алгоритм Ву улучшает визуальное качество линий, но требует дополнительных вычислений. Созданное приложение позволяет наглядно исследовать работу алгоритмов и сравнивать их временные характеристики.
