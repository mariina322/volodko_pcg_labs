# RasterLab — лабораторная работа №4


## Реализовано
- Пошаговый алгоритм.
- ЦДА (DDA).
- Обобщённый алгоритм Брезенхема для отрезка (все октанты).
- Алгоритм Брезенхема для окружности (8-кратная симметрия).
- Алгоритм Ву с дробным распределением интенсивности между соседними пикселями.
- Виртуальный растр `Float32Array`; алгоритмы записывают интенсивность через `setPixel`.
- Отдельная функция `render()` отображает содержимое растра, координатные оси, сетку и подписи.
- Масштабирование и просмотр координат ячеек.
- Бенчмарк: полный режим содержит 100 000 случайных отрезков и 50 000 окружностей; быстрый режим предназначен для предварительной проверки.
- Сравнительная диаграмма и график времени от количества отрезков.
- Экспорт результатов в CSV.

## Важные замечания
1. Алгоритмы не используют `Canvas` API для рисования линий или окружностей. Они только вызывают `setPixel` у виртуального растра.
2. Canvas используется исключительно модулем отображения: для вывода ячеек, сетки, осей и подписей.
3. Пошаговый алгоритм и ЦДА в классическом виде используют одинаковую схему приращений с округлением; в данном учебном приложении они выделены отдельными методами, чтобы можно было сравнивать их в интерфейсе.
4. Бенчмарк измеряет вычисление и запись в виртуальный массив, но не отрисовку. На время влияет браузер, процессор, размер растра и фоновая нагрузка. Для отчёта рекомендуется выполнить тест 3 раза и привести среднее или медианное значение.
5. Реализация Кастла—Питвея не включена: название в задании неоднозначно и требует сверки с конкретным учебным описанием/источником преподавателя. Не следует выдавать другой алгоритм конических сечений за Кастла—Питвея.

## Соответствие координат
Виртуальная сетка имеет размер 129×129. Координаты x,y ∈ [-64,64]. Ячейка массива с индексами (ix,iy) соответствует математической координате (ix-64, 64-iy). Поэтому положительное направление Y направлено вверх, хотя индексы строк массива растут вниз.

## Файлы
