# Отчёт по лабораторной работе № 4
## «Базовые растровые алгоритмы»

### 1. Цель работы

Изучить принципы растеризации графических примитивов и реализовать алгоритмы построения отрезков и окружностей на дискретной сетке. Сравнить алгоритмы по принципу работы и времени выполнения.

### 2. Средства разработки

Приложение реализовано с использованием HTML, CSS и JavaScript. Для отображения графики используется элемент `canvas`.

Построение выполняется на виртуальной растровой сетке. Алгоритм определяет, какие пиксели необходимо закрасить, после чего приложение отображает результат.

### 3. Реализованные алгоритмы

#### 3.1. Пошаговый алгоритм построения отрезка

Пусть заданы начальная точка $A(x_1,y_1)$ и конечная точка $B(x_2,y_2)$.

Сначала вычисляются приращения координат:

$$
\Delta x = x_2-x_1,\qquad \Delta y = y_2-y_1
$$

Количество шагов определяется по наибольшему приращению:

$$
N = \max(|\Delta x|,|\Delta y|)
$$

Приращения координат на каждом шаге равны:

$$
x_{\text{ш}} = \frac{\Delta x}{N},\qquad
y_{\text{ш}} = \frac{\Delta y}{N}
$$

Начиная с точки $A$, алгоритм последовательно прибавляет приращения к текущим координатам. На каждом шаге координаты округляются до целых значений, соответствующих пикселям.

Алгоритм прост в реализации и подходит для отрезков разных наклонов. Однако он использует вещественные вычисления, а последовательное округление может приводить к накоплению погрешности.

#### 3.2. Алгоритм цифрового дифференциального анализатора (ЦДА, DDA)

Алгоритм ЦДА строит отрезок последовательным вычислением координат пикселей. Для заданных точек вычисляются:

$$
\Delta x = x_2-x_1,\qquad \Delta y = y_2-y_1
$$

Затем определяется количество шагов:

$$
N = \max(|\Delta x|,|\Delta y|)
$$

На каждом шаге координаты изменяются на величины:

$$
x_{\text{ш}} = \frac{\Delta x}{N},\qquad
y_{\text{ш}} = \frac{\Delta y}{N}
$$

Алгоритм начинает работу с точки $(x_1,y_1)$. После каждого шага к текущим координатам прибавляются $x_{\text{ш}}$ и $y_{\text{ш}}$, а полученные значения округляются до координат пикселя.

ЦДА подходит для отрезков любого наклона, но использует вещественные числа и может накапливать погрешность округления.

#### 3.3. Алгоритм Брезенхема для построения отрезка

Алгоритм Брезенхема строит отрезок преимущественно с помощью целочисленных вычислений. На каждом шаге он выбирает пиксель, наиболее близкий к идеальному положению линии.

Сначала вычисляются абсолютные приращения:

$$
\Delta x = |x_2-x_1|,\qquad
\Delta y = |y_2-y_1|
$$

Направления изменения координат определяются следующим образом:

$$
s_x =
\begin{cases}
1, & x_1 < x_2,\\
-1, & x_1 \ge x_2
\end{cases}
\qquad
s_y =
\begin{cases}
1, & y_1 < y_2,\\
-1, & y_1 \ge y_2
\end{cases}
$$

Для выбора следующего пикселя используется параметр ошибки. В зависимости от наклона отрезка алгоритм изменяет координату вдоль главного направления, а при необходимости — и вторую координату.

Обработка разных соотношений $\Delta x$ и $\Delta y$ позволяет строить отрезки во всех восьми октантах.

Алгоритм не требует вычисления вещественных координат на каждом шаге и обычно эффективен для растеризации линий.

#### 3.4. Алгоритм Брезенхема для построения окружности

Алгоритм строит окружность по одному октанту, используя её симметрию. Пусть центр окружности имеет координаты $(x_c,y_c)$, а радиус равен $r$. Построение начинается с точки:

$$
x=0,\qquad y=r
$$

На каждом шаге алгоритм выбирает следующий пиксель, используя целочисленный параметр решения. Он определяет, нужно ли уменьшить координату $y$.

Для каждой найденной точки $(x,y)$ относительно центра окружности строятся восемь симметричных точек:

$$
(x_c+x,\ y_c+y),\quad (x_c-x,\ y_c+y)
$$

$$
(x_c+x,\ y_c-y),\quad (x_c-x,\ y_c-y)
$$

$$
(x_c+y,\ y_c+x),\quad (x_c-y,\ y_c+x)
$$

$$
(x_c+y,\ y_c-x),\quad (x_c-y,\ y_c-x)
$$

Построение продолжается до достижения границы первого октанта. Остальные точки окружности получаются отражением найденных точек.

Алгоритм использует целочисленные вычисления и позволяет строить окружность без вычисления квадратного корня для каждой точки.

#### 3.5. Алгоритм Ву для сглаживания отрезка

Алгоритм Ву строит сглаженные линии, закрашивая соседние пиксели с разной интенсивностью. Интенсивность зависит от расстояния идеальной линии до центра пикселя: чем ближе линия к центру, тем ярче пиксель.

Алгоритм учитывает наклон отрезка. Если линия круче диагонали, координаты меняются местами, чтобы построение выполнялось вдоль главного направления. Затем для соседних пикселей вычисляются интенсивности на основе дробной части координаты линии.

Алгоритм уменьшает ступенчатость линий, но требует дополнительных вычислений по сравнению с обычными алгоритмами растеризации.

### 4. Интерфейс приложения

Приложение содержит область построения, панель управления и раздел тестирования производительности.

Пользователь может выбрать алгоритм, задать координаты отрезка или параметры окружности и выполнить построение. Масштаб сетки изменяется вместе с масштабом отображения, что позволяет рассматривать построенные примитивы при разных уровнях увеличения.

Для сравнения алгоритмов предусмотрен отдельный раздел с графиками и таблицей результатов. Результаты измерений можно сохранить в CSV-файл.

### 5. Тестирование производительности

Для оценки производительности предусмотрен бенчмарк. Он измеряет время выполнения алгоритмов на наборах отрезков и окружностей и отображает результаты отдельно для разных алгоритмов.

Полученные значения позволяют сравнить время обработки входных данных. На результат могут влиять характеристики компьютера, браузера и объём тестового набора.

### 6. Результат работы

Разработано веб-приложение для построения растровых отрезков и окружностей. Реализованы пошаговый алгоритм, алгоритм ЦДА, алгоритм Брезенхема для отрезка и окружности, а также алгоритм Ву для сглаживания линий.

В приложении предусмотрены масштабируемая сетка, управление параметрами построения и инструменты сравнения времени выполнения алгоритмов.

### 7. Вывод

В ходе лабораторной работы были изучены принципы растеризации графических примитивов. Реализованные алгоритмы используют разные подходы к выбору пикселей: последовательное вычисление координат, целочисленный выбор ближайшего пикселя и сглаживание с помощью интенсивности.

Алгоритмы Брезенхема позволяют строить отрезки и окружности с использованием целочисленных вычислений. Алгоритм Ву улучшает визуальное качество линий, но требует дополнительных вычислений. Созданное приложение позволяет наглядно исследовать работу алгоритмов и сравнивать их временные характеристики.
