# Лабораторная работа № 1 — Цветовые модели

Вариант 6: `CMYK ↔ RGB ↔ HLS`.

Статическое веб-приложение на HTML, CSS и vanilla JavaScript. Внешние библиотеки преобразования цветов не используются. Проект можно разместить на GitHub Pages без сборки.

## Возможности

- изменение цвета числовыми полями, ползунками и системной палитрой;
- автоматический пересчёт RGB, CMYK и HLS;
- алгоритмы цветоделения UCR и GCR;
- выбор белой точки D65, D50 или E;
- расчёт матриц `linear RGB ↔ XYZ` из координат основных цветов и белой точки во время работы программы;
- перевод `RGB ↔ XYZ ↔ CIELAB`;
- стратегии Clipping и Scaling для цветов вне охвата RGB;
- динамический градиент каждого ползунка с учётом остальных текущих компонентов;
- отдельные автоматические микро-тесты математического слоя.

## Структура

Проект разделён по схеме MVC:

- `js/model/color-model.js` — формулы и матричные операции;
- `js/view/color-view.js` — работа только с элементами страницы;
- `js/controller/color-controller.js` — обработка действий пользователя и связь слоёв;
- `tests/color-model.test.js` — тесты математики.

## Запуск

Основное приложение можно запустить обычным двойным щелчком по `index.html`. Для режима, максимально похожего на GitHub Pages, можно также использовать локальный сервер:

```text
python -m http.server 8000
```

После этого открыть `http://localhost:8000`. Для запуска тестов из консоли:

```text
npm test
```

Браузерная страница с теми же проверками находится в `tests/tests.html`; в основном интерфейсе ссылка на неё не выводится.

## Принятые формулы

RGB линеаризуется по передаточной функции sRGB. Матрица перехода в XYZ не хранится как готовая константа: она строится из хроматических координат основных цветов sRGB и текущей белой точки. Обратная матрица вычисляется аналитически через определитель и алгебраические дополнения.

В GCR вся общая серая составляющая `min(C, M, Y)` заменяется каналом K. В UCR замена включается плавно только после 50% серой составляющей, то есть в тенях. При обратном переводе сохраняется исходный RGB-цвет.
