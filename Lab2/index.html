Особенности реализации

  • Обработка выполняется в Web Workers.
  • Файлы не загружаются целиком в память.
  • Используется частичное чтение через File.slice().
  • JPEG просматривается блоками по 64 КБ.
  • PNG анализируется по chunks.
  • TIFF анализируется по IFD и тегам.
  • Основной поток браузера остаётся отзывчивым.
