ЛАБОРАТОРНАЯ РАБОТА 2
Чтение информации из графических файлов

СТРУКТУРА ПРОЕКТА

index.html
Интерфейс приложения.

style.css
Оформление страницы.

script.js
Основной поток браузера:
- выбор папки;
- очередь файлов;
- пул Web Workers;
- прогресс;
- таблица результатов;
- фильтрация.

worker.js
Разбор файлов:
- определение формата по сигнатуре;
- частичное чтение через File.slice();
- ручной разбор JPEG, PNG, GIF, BMP, TIFF, PCX.

package.json
Команда запуска локального HTTP-сервера.

start.sh
Запуск проекта на macOS/Linux.

start.bat
Запуск проекта на Windows.


ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ

JPG / JPEG
PNG
GIF
BMP
TIF / TIFF
PCX


ПОЛУЧАЕМАЯ ИНФОРМАЦИЯ

- имя файла;
- формат;
- ширина;
- высота;
- разрешение;
- глубина цвета;
- тип сжатия;
- статус корректности.


ОСОБЕННОСТИ РЕАЛИЗАЦИИ

1. Метаданные не извлекаются сторонней библиотекой.
2. Формат определяется по сигнатуре файла.
3. Используется File.slice(), поэтому файл не загружается целиком.
4. Обработка выполняется в Web Workers.
5. Используется пул из нескольких Worker.
6. JPEG после SOS просматривается блоками по 64 КБ.
7. PNG читается по структуре chunks.
8. TIFF читается по структуре IFD и отдельным тегам.
9. Ошибка одного файла не останавливает обработку остальных.
10. Интерфейс остаётся доступным во время обработки.


ЗАПУСК НА macOS / Linux

Требуется Node.js.

1. Откройте Terminal.
2. Перейдите в папку проекта:

cd /путь/к/Lab2_ImageMetadata

3. Один раз выполните:

chmod +x start.sh

4. Запустите:

./start.sh

5. Откройте:

http://localhost:3000


Можно запустить без start.sh:

npm start


ЗАПУСК НА WINDOWS

1. Установите Node.js.
2. Дважды щёлкните start.bat.

Или выполните:

npm start


ПОЧЕМУ НУЖЕН ЛОКАЛЬНЫЙ СЕРВЕР

Приложение использует Web Worker:

new Worker("worker.js")

При открытии index.html напрямую через file:// некоторые браузеры
ограничивают загрузку worker.js.

Поэтому проект запускается через:

http://localhost:3000
