# Лабораторная работа 3 — Обработка цифровых изображений (Группа 10А, Вариант 6)

## Запуск приложения
1. Откройте папку с проектом.
2. Дважды нажмите `index.html` — веб-приложение откроется в браузере (установка дополнительных библиотек или сервера не требуется).
3. Загрузите тестовое изображение, выберите метод из списка, настройте параметры и нажмите «Обработать изображение».
4. При необходимости сохраните результат кнопкой «Скачать результат PNG».

## Реализованные методы (Вариант 6)
1. **Поэлементные операции и линейное контрастирование:**
   - Линейное контрастирование (растяжение динамического диапазона `[Ymin; Ymax] -> [0; 255]`).
   - Изменение яркости (аддитивная коррекция).
   - Гамма-коррекция (нелинейное степенное преобразование).
   - Инверсия (негатив изображения).
2. **Глобальная пороговая обработка (2 метода на выбор):**
   - Метод Оцу (Otsu) с автоматической максимизацией межклассовой дисперсии.
   - Итеративный метод подбора порога (ISODATA / Ридлера–Калварда).
3. **Адаптивная пороговая обработка:**
   - Метод Сауволы (Sauvola) с использованием интегральных изображений (Summed-Area Table, SAT) со сложностью `O(1)` на пиксель и выбором стратегии обработки краёв (`Reflect` и `Clamp`).

## Архитектура проекта (требования группы 10А)
- `index.html`, `style.css` — **Presentation Layer (UI)**: отображение исходного и обработанного изображений, гистограмм яркости и элементов управления.
- `script.js` (`PixelBuffer`) — **Memory & Pixel Access Layer**: прямой доступ к массиву пикселей `ImageData` и обработка граничных условий (`Reflect` / `Clamp`).
- `script.js` (`Algorithms`) — **Processing Layer**: чистые функции фильтрации, контрастирования и бинаризации.
