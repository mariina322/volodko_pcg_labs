# Лабораторная работа 3 — обработка цифровых изображений (группа 10А)

## Запуск на macOS
1. Распакуйте архив `Lab3_10A.zip`.
2. Откройте папку `Lab3_10A`.
3. Дважды нажмите `index.html` — проект запускается в браузере, установка Python, Java или C# не требуется.
4. Загрузите изображение, выберите метод, нажмите «Обработать изображение».
5. Сохраните результат кнопкой «Скачать результат PNG».

Для локального веб-приложения отдельный сервер и `package.json` не нужны.

## Что реализовано
- линейное растяжение контраста и изменение яркости;
- выравнивание гистограммы яркости;
- CLAHE (ограниченное локальное выравнивание гистограммы по плиткам);
- усредняющий и гауссов фильтры с двумя одномерными проходами;
- медианный фильтр;
- повышение резкости;
- оператор Собеля, величина градиента и цветная карта направления `atan2(Gy, Gx)` (нажмите на результат, чтобы переключить карту);
- глобальная бинаризация Отсу;
- адаптивная бинаризация Sauvola с интегральными изображениями для суммы яркости и квадрата яркости;
- дилатация, эрозия, морфологический градиент, Top-Hat и Black-Hat;
- обработка границ Reflect и Clamp;
- гистограммы исходного и обработанного изображения.

## Важные ограничения
- Алгоритмы реализованы вручную на JavaScript по массивам пикселей `ImageData`; встроенные фильтры браузера не используются.
- CLAHE использует сетку 8×8 и билинейную интерполяцию между картами соседних плиток.
- Для очень больших изображений (например, 10000×10000) обработка в основном потоке браузера может занять заметное время.
- Результат большинства методов переводится в оттенки серого, поскольку методы фильтрации/сегментации здесь демонстрируются по интенсивности яркости.
- Карта направления Собеля показывается переключением по клику на изображении результата.

## Структура
- `index.html` — интерфейс;
- `style.css` — оформление;
- `script.js` — алгоритмы обработки и работа интерфейса.
